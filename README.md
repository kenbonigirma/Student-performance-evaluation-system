# Student Performance Evaluation System

This is a JavaScript project that checks a student's performance.

The program stores information about a student like name, age, course, score, and attendance.

Then it calculates the grade, checks if the student passed or failed, and checks if the student can take the exam.

## How to Run This Project on Ubuntu

Step 1: Download or open your project folder

Step 2: Find the file named index.html

Step 3: Right-click on index.html

Step 4: Click "Open with" and choose your browser (Chrome, Firefox, or any browser)

Step 5: The page will open in your browser

Step 6: You will see a heading that says "Student Performance Evaluation System"

Step 7: You will also see text that says "Open the browser console to see the student report."

Step 8: Press Ctrl + Shift + I on your keyboard
(On Ubuntu: Use Ctrl + Shift + I or right-click and select "Inspect")

Step 9: A box will open at the bottom or side of your browser

Step 10: Look for a tab that says "Console"

Step 11: Click the Console tab

Step 12: Now you will see all the output from your JavaScript program

That's it! You do not need to install anything. You just need a browser.
